# Word Redline 2.2 — Windows

Word 比对检测到 0 项修订时，生成 `新版文件名 - 无差别.txt`，作为本次比对记录。有修订时继续生成 `新版文件名 - redline.docx`。

- TXT 记录结论、新旧文件名称与完整路径、带时区的完成时间、软件及 Word 版本、源文件 SHA-256 和比较范围。
- 单组无差别时弹窗提示；批量在全部完成后统一提示修订、无差别与失败数量，中途不弹窗。
- 界面分别显示“存在修订”“无差别”“比对失败”，“打开结果”支持 DOCX 和 TXT。
- TXT 沿用原目录 / Legal / 自定义子文件夹设置，重名自动编号，不覆盖源文件或既有输出。

“无差别”指 Word 本次比较未检测到修订，不代表两个文件的二进制数据完全相同。TXT 是可编辑的本地记录，不是防篡改凭证。

完整解压绿色版后双击 `Word Redline.exe`。需要 Windows 10/11 和 Microsoft Word 桌面版。
