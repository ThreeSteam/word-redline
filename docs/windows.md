# Word Redline 2.1 绿色版

将新、旧 Word 文档分别拖入界面，确认配对后，一键调用 Microsoft Word 原生比较功能，生成保留修订标记的 Redline 文档。支持单组及批量比对。

## 1. 快速开始

1. 将压缩包完整解压到一个文件夹。
2. 双击 **Word Redline.exe**。
3. 左侧拖入旧版，右侧拖入新版；每侧都可以一次拖入多个文件。
4. 检查下方配对预览，必要时在“对应旧版”列下拉修改。
5. 点击 **开始比对**。仅拖入文件不会启动比对。
6. 完成后，选中一行点击 **打开结果**，或双击该行的结果状态。

结果默认保存在**对应新版文件所在文件夹**；开启保存到子文件夹后，保存到该目录下的 Legal 或自定义文件夹。

## 2. 运行要求

- Windows 10 / 11。
- 已安装且能正常使用的 **Microsoft Word 桌面版**。本工具不包含 Office，不能以 WPS 或网页版 Word 代替。
- 系统可运行 .NET Framework 和 Windows PowerShell；不需要安装 Python、开发工具或额外插件。
- 对新版文件所在文件夹具有写入权限。

请使用普通用户权限启动。以管理员身份运行可能导致无法从普通文件管理器拖入文件。

## 3. 文件夹结构与迁移

```text
Word Redline 绿色版/
├── Word Redline.exe     # 启动程序与界面
├── CompareWorker.ps1    # Word 比对与保存逻辑
├── WordNative.ps1       # 独立 Word 实例连接组件
├── README.md           # 完整使用说明
└── 使用说明.txt          # 简版使用说明
```

绿色版无需安装。可将**整个文件夹**复制到其他磁盘、U 盘或另一台电脑，再运行其中的 EXE。

不要只复制 EXE，也不要移动或重命名两个 PS1 文件。迁移后的电脑仍需满足上述运行要求。使用 ZIP 时，请先解压，不要直接在压缩包中运行。

## 4. 单组与批量操作

### 添加、移除文件

- 可一次拖入一份或多份文件，也可以分次追加。
- 不便拖拽时，点击左右两侧的 **添加文件…**。
- 拖错文件后，在对应列表中选中它，点击 **移除选中**，或按 `Delete`，再添加正确文件。
- 支持 `.docx`、`.doc`、`.docm`。非 Word 文件和以 `~$` 开头的 Word 临时文件会被忽略。
- 添加或移除文件会重新生成配对建议，请重新核对已调整的配对。

### 批量配对示例

两侧文件顺序和完整文件名都不必相同。例如：

| 旧版 | 新版 | 建议对应关系 |
| --- | --- | --- |
| 项目A_投资协议_定稿.docx | 项目A_增资协议_0914.docx | 投资协议 ↔ 增资协议 |
| 项目A_股东协议_0706.docx | 项目A_股东协议_修订版.docx | 股东协议 ↔ 股东协议 |
| 项目A_章程.docx | 项目A_章程_新版.docx | 章程 ↔ 章程 |

程序识别投资协议 / 增资协议、股东协议、章程、股权转让等关键词，并结合去除日期、版本及“定稿”等标记后的文件名相似度，生成一对一建议。

**配对依据是文件名，不是正文内容。建议配对仍需核对。** 多个候选相近或无法判断时，会显示“待手动配对”，不会强行凑对。两侧各只有一份不同文件时，会直接建议将它们配成一组。

### 确认与调整

- 每份新版在预览表中对应一行，在“对应旧版”列选择它的旧版本。
- 鼠标悬停在预览表的文件单元格上，可查看路径提示。
- 不需要执行的行，取消最左侧“比对”勾选。
- 新旧两侧文件数量可以不同；未使用的旧版不会参与比对。
- 点击 **开始比对** 前，所有勾选行都必须完成配对。
- 同一旧版不能用于多条勾选行；同一个文件也不能与自己比较。

## 5. 保存位置与命名

每组结果分别保存到该组新版目录，或所选子文件夹，统一输出为 `.docx`：

```text
新版：投资协议_0914.docx
结果：投资协议_0914 - redline.docx
```

如果已经存在同名结果，则自动增加编号：

```text
投资协议_0914 - redline (2).docx
投资协议_0914 - redline (3).docx
```

源文件只读打开，不覆盖源文件或已有结果。请先在 Word 中保存最新修改，本工具比较的是磁盘上已保存的版本。

## 6. 进度、取消与再次执行

- 批量任务按行依次执行，显示启动 Word、打开旧版、打开新版、比较、保存等阶段。
- 单组失败后会继续后续组，并在该行显示失败原因。
- 完成后显示本批次成功、失败数量。
- **停止比对** 会停止当前组和待执行组；已经生成的结果文件保留。
- 比较阶段最多等待 10 分钟，其他阶段最多等待 90 秒；超时会标明失败阶段。
- 重试失败组时，可以只勾选需要重试的行，再点击 **开始比对**。仍勾选的成功行也会重新执行，并生成编号结果。
- 开始下一批文件前，点击 **清空**。这只清空界面列表，不删除文件。

## 7. 常见问题

### 双击后无法启动

确认已完整解压，EXE 和两个 PS1 文件在同一文件夹。若提示文件缺失，重新完整解压后再试。公司电脑若禁止执行 PowerShell 脚本，需要由 IT 确认允许运行此工具。

### 无法拖入文件

不要以管理员身份运行；重新以普通权限启动。也可以通过“添加文件…”选择文件。比对执行中不能修改文件列表，需要等待结束或先取消。

### 配错了，或显示“待手动配对”

在预览表的“对应旧版”下拉框中重新选择。若多份文件都包含“投资协议”等相同关键词，建议在文件名中补充项目名、公司名等区分信息。开始前仍应逐行核对。

### 点击开始后没有执行

查看窗口下方提示。常见原因是存在未配对的勾选行、重复使用同一旧版、新旧指向同一个文件，或文件已被移动、删除。

### 找不到 Word、打开失败或超时

先确认 Microsoft Word 桌面版能够正常启动并打开两份原文件。带密码、受保护或损坏的文件可能无法自动处理。云盘文件请先确保已下载到本地；执行期间不要移动或重命名源文件。

### 保存失败或找不到结果

结果在对应新版目录或所选子文件夹。确认该位置可写、磁盘空间充足，并查看该行是否显示完成。多个新版来自不同文件夹时，结果也会分别保存在各自文件夹。

### 能否在没有 Word 的电脑上使用

不能。绿色版省去的是本工具的安装步骤，实际比较仍由该电脑上的 Microsoft Word 完成。

## 8. 技术与数据说明

- 界面使用 Windows Forms；比较通过独立 Word 实例调用原生 `CompareDocuments`。
- 比较结果通过完整 WordOpenXML 文档包导出，保存 Word 原生修订标记，避开本机曾出现的 `SaveAs2` 挂起问题。
- 本工具不上传文档，不依赖在线比对服务；Word 自身及云盘客户端的联网行为仍由各自设置决定。
- 不安装常驻服务，不由本工具写入注册表。临时任务记录位于 `%TEMP%\WordRedline`，可能包含本次文件路径。
