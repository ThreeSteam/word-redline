# Word Redline 2.1 — Windows

Windows 2.1 更新了整体界面，并增加了可配置的结果保存位置。

## 本次更新

- 全新 Windows 11 风格界面：卡片布局、圆角控件、清晰的配对预览和状态反馈。
- 全新应用图标，已嵌入 EXE，并在绿色版中附带 ICO 与 PNG 文件。
- 新增“保存到子文件夹”开关，默认关闭。
- 开启后默认保存到新版文件所在目录下的 `Legal` 文件夹，也可以自定义文件夹名称。
- 保留批量智能配对、手动调整、开始前确认和重名自动编号功能。

## 下载与运行

下载 `Word-Redline-2.1-Windows-Portable.zip`，完整解压后双击 `Word Redline.exe`。

运行环境：Windows 10/11、Microsoft Word 桌面版、系统自带 .NET Framework 和 Windows PowerShell。无需安装本工具或其他开发环境。

macOS 版本仍为 2.0，可从之前的 2.0 Release 下载。
